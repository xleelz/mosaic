## Benchmark corrections (verified against the code)

- **Default world (preamble).** The merged world does *not* pin 2048 / 128. Its `max-num-batched-tokens` is 8192 and `max-num-seqs` 1024, which is what `vllm serve` derives on the fixture's H100 (`arg_utils.py:2933-2942,3112-3127`). The model is right here. Cases that depend on 2048 / 128 (Q4-1 (d) "128 seqs", Q4-8's 2048-token chunks) set those configs explicitly.
- **Q4-2 (d).** The HTTP status is **400**. `RepetitionDetectionParams.__post_init__` raises `VLLMValidationError`. That class is a `VLLMClientError`, not a `ValueError` (`vllm/exceptions.py:28`), so pydantic doesn't wrap it, and the `VLLMError` handler maps it to `BAD_REQUEST` (`serve/exception_handling/register.py:32`, `error_response.py:41-43`). Read from the code, not run.
- **Q4-3 (a).** Confirmed. `data_parallel_rank` is stamped to 0 by the publisher (`kv_events.py:392-393`), so even with `omit_defaults` the batch is a 3-element array. `BlockStored`'s `lora_id`, `medium` and `lora_name` have no defaults and are always encoded. `extra_keys: None` is omitted.
- **Q4-5 (d) setup.** Under FCFS a KV-blocked A at the head of the waiting queue stops admission (`scheduler.py:1275-1282`, `break`), so C can't be admitted while A waits. The case needs the priority policy, with C ahead of A. It was driven that way, and A's preemption was driven with `scheduler.preempt-request`.
- **Q4-6.** The world's checkpoint is `neuralmagic/Meta-Llama-3-8B-Instruct-FP8-KV` (`quant_method: fp8`, `kv_cache_scheme: static`). It isn't ModelOpt, so `auto` stays `auto` (`torch_utils.py:466-499`). Weights are 8.46 GiB vs 14.96 GiB, a difference of exactly 3,328 blocks / 53,248 tokens. Available memory also subtracts the CUDA-graph estimate (`gpu_worker.py:740-744`). That doesn't change the difference.
- **Q4-1 / Q4-4 / Q4-7 / Q4-8.** Every other cited line matches v0.32.0 as written (Llama-3.1 EOS 128009 and gen-config [128001, 128008, 128009]; `use_batched_dp_moe` `parallel.py:791-801`; iteration buckets `buckets.py:107-121`; observation = computed + generated `loggers.py:1273-1276`).

## Wrong claims found in the model

1. `event-publisher-factory.create` (cites `kv_events.py:582-597`): enabling KV events with no publisher yields `NullEventPublisher`. The code defaults the publisher to `"zmq"` (`config/kv_events.py:50-52`), so the model publishes nothing in the standard `--kv-events-config '{"enable_kv_cache_events": true}'` deployment.
2. `engine-args.set-default-max-num-seqs-and-batched-tokens-args`: claims to cover `arg_utils.py:3097-3187` but drops the batched-DP-MoE default of 256 (3113-3117). `create-engine-config` also never forwards `all2all_backend`.
3. `sched-utils.check-stop`: its summary covers only EOS, stop ids and length. The cited range includes the `min_tokens` gate and `FINISHED_REPETITION` (`utils.py:121-138`). `sampling-params.post-init` lacks the `RepetitionDetectionParams` validation (`sampling_params.py:186-202`).
4. `block-pool.cache-full-blocks` (cites `block_pool.py:333-345`): BlockStored lacks parent, token_ids, block_size, medium and lora fields. There's no `emit_cached_block_events` (378-445) and no `AllBlocksCleared` on reset (862-864).
5. Engine-args / `gpu-model-runner.get-kv-cache-spec`: `auto` is never resolved from a ModelOpt quant config (`torch_utils.py:466-499`).
6. `output-processor.process-outputs` hardcodes `num_preempted_reqs: 0`, so `vllm:num_preemptions` never moves, though the output carries a PREEMPTED event (code: `stats.py:572-574`). `record-prometheus` omits `prompt_tokens_by_source`, `prompt_tokens_cached` and `iteration_tokens_total` (`loggers.py:1262-1276`).
7. `base-multi-modal-processor.apply`: the identity is the URL, not the decoded content, and a uuid is hashed rather than used verbatim (`inputs.py:89-105`). `input-processor.process-inputs` hardcodes Llama-3.1's EOS 128009 and [128001, 128008] for every model (a labeled constant), which is wrong for the FP8 world's generation config [128001, 128009].
8. Minor: `cuda-graph-manager.init` omits the `min(max_num_batched_tokens, ...)` clamp (`vllm.py:2446`). `kv-cache-utils.init-none-hash` is never called (code `core.py:234-236`).

Citation spot check (`--cite-sample 12 --seed 404`, plus about 12 hand-read in this group): all 9,925 citations resolve, and the 12 sampled citations match their claims. The wrong claims above are omissions inside correctly cited ranges, not bad lines.
