## Fix requests

### scheduler-kv

1. **External computed tokens.** Add `num_external_computed_tokens` to `kv-cache-manager.allocate-slots`: include it in the "nothing to allocate" guard and in `total_computed_tokens` (`kv_cache_manager.py:474-503`), and when > 0 call a new `full-attention-manager.allocate-external-computed-blocks` that allocates `max(0, cdiv(local + external, block_size) - len(req_blocks))` blocks (`single_type_kv_cache_manager.py:326-366`), after adopting local hits (`kv_cache_coordinator.py:296-309`).
2. **KV connector in scheduling.** When a connector is configured, `scheduler.schedule` must ask it for external hits for waiting requests (`scheduler.py:979`) and pass them to `allocate-slots` (`:1262`), plus load-async handling. Coordinate with distributed on `SimpleCPUOffloadConnector`.
3. **Hybrid KV cache.** Model the hybrid coordinator and `MambaManager` (`kv_cache_coordinator.py`, `single_type_kv_cache_manager.py`): per-group block sizes, `scheduler_block_size` = LCM, and the longest hit common to all groups.
4. **Outlines validation.** Add the outlines request validator (`backend_outlines.py:195-368`): reject backreferences, lookarounds and `\b`/`\B`, including inside groups and repeats, plus missing universal start state; and stop routing `backend: outlines` to `xgrammar-backend.compile-grammar` in `structured-output-manager.grammar-init`.

### engine-core

1. `input-processor.process-inputs` should run `SamplingParams.verify` structured-output validation (`input_processor.py:157`, `sampling_params.py:1218-1440`) with the configured backend, failing `vllm-validation-error`. (Needs a structured-outputs backend config; see config-platform.)

### distributed

1. Add `SimpleCPUOffloadConnector` (`kv_connector/v1/simple_cpu_offload_connector.py`, `vllm/v1/simple_kv_offload/`): scheduler-side `get_num_new_matched_tokens` from CPU-resident blocks, eager store after compute, load on hit; CPU copies survive a GPU `reset_prefix_cache`.

### worker-runner

1. **Non-last PP rank.** In `gpu-model-runner.sample-tokens`, add the `not is_last_pp_rank` branch (`model_runner.py:2108-2127`): PCP global batch, `pp_handler.receive`, `postprocess_num_computed_tokens`, `postprocess_state(idx_mapping, 0)` unless all decode, `kv_connector.post_forward`, KV-only output; no sampling. Needs a PP rank role in the topology/state.
2. **EPLB.** Add an EPLB controller to `gpu-model-runner.load-model` (`eplb_utils.py:94-165`): `prepare_load` creates the state when `enable_eplb`; register the MoE model (and MoE drafter) with `add_model`; start the async loop unless loading dummy weights.
