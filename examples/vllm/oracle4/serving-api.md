## Fix requests

### serving-api

1. **serving-scores.serve-score: request shapes.** Read `items` as data_2 and `data_1`/`data_2` as the pair. Unwrap a list `text_1` the way `queries` is unwrapped (scoring/protocol.py:84-127).
2. **serving-scores.serve-score: error propagation.** A tokenize failure (over max_model_len) inside the per-pair `parallel` must surface as the VLLMValidationError (400). Today the join fails `insufficient` and the client gets a 500. Catch it in the branch (`on_error: continue` on tokenize-prompt) as is already done for encode, or fail with the branch error.
3. **serving-scores.serve-score: tokenization params.** Honour `truncate_prompt_tokens` (reject when > max_model_len with "Please request a smaller truncation size.", renderers/params.py:270-281) and `max_tokens_per_query`/`max_tokens_per_doc`: validate them (non-negative, < max_model_len; io_processor.py:110-141) and truncate each text. Compute usage from the prompt token ids, not from the count of texts. Pass `use_activation` into pooling_params.
4. **sagemaker-router.post-invocations.** Add the pooling invocation types in order: embed/classify request by pooling task, RerankRequest, ScoreRequest, PoolingRequest (pooling/factories.py:221-272; sagemaker/api_router.py:81-84).
5. **serving-pooling.post-pooling / pooling-base-serving.serve.** Use `body.task`, defaulting to the model pooling task, and apply `_verify_pooling_task` (pooling/serving.py:61-99): "Unsupported task: ..." when the task is not in supported_tasks, "Try switching the model's pooling_task via --pooler-config.task ..." when it is supported but is not the pooling task, and "No IOProcessor plugin installed." for plugin. Return a PoolingResponse (`data`, not `embedding`). Also accept a string `input` (the schema says array only).
6. **llm.encode.** Accept `pooling_params` (a single value, a list or None). A list whose length differs from the prompts raises VLLMValidationError (pooling/base/io_processor.py:307-320).
7. **base-renderer: add `_truncate_expanded_prompt`.** Called from `_process_singleton` (renderers/base.py:1035-1130). For a multimodal input with truncate_prompt_tokens, slice the expanded ids to the limit on truncation_side. Reject with VLLMValidationError (param truncate_prompt_tokens) when any placeholder span would be split or dropped. Shift the placeholder offsets on left truncation.

## Untranslatable

- `test_replay`: streaming parser chunk/holdback invariance and terminal-marker leakage, which are lexer internals.
