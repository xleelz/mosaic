## Fix requests

### kernels-ops
- **`support-torch-compile.call` must honour the module's `do_not_compile`.** `decorators.py:528` returns `self.forward(...)` when `do_not_compile` is set, and `do_not_compile` includes `_should_ignore_torch_compile(cls)` and `not enable_if(...)` (`decorators.py:402`). Record `do_not_compile` per decorated class or module in `init` (for example `state.modules[cls]`), and have `call` take a `cls` input and return `path: eager` with no counter increments when it is set.
- **Make `compiled`, `aot_compiled_fn` and `num_compiles` per module instance**, not per component. `__init__` sets `self.compiled = False` for each new module (`decorators.py:415`), so a second `@support_torch_compile` module (C after A) compiles again.
- (Minor) `support-torch-compile.decorate` could record `state.ignored[cls] = false` (`decorators.py:363`), so that a subclass of an ignored class is visibly un-ignored. The current `init` reaches the right answer only because `ignored` is keyed by exact class name and does no inheritance lookup.
