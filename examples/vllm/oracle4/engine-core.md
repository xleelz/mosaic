## Fix requests

- **engine-core** (`output-processor.process-outputs`): build `CompletionOutput.logprobs` from the request's accumulated logprobs (`state['logprobs-processor'].requests[rid]`), whether or not this step carried `new_logprobs`. DELTA slices the last `len(new_token_ids)` positions (`[:0]` when there are none), and CUMULATIVE returns the whole list. Return null only when the request didn't ask for logprobs (output_processor.py:441-448).
- **engine-core** (`async-llm.add-request` / `input-processor.process-inputs`): model the prompt parse (`parse_model_prompt`, preprocess.py:129-151, 228-232). A prompt carrying `encoder_prompt` for a decoder-only model raises a TypeError, and `generate` turns it into `engine-generate-error` (not `vllm-validation-error`). This needs a prompt-shape field (for example `encoder_prompt`) on the generate request.
