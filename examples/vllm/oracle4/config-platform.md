## Fix requests

- **config-platform** (`model-config.post-init`): resolve the ModelArchitectureConfig the way `ModelArchConfigConvertorBase.convert()` does, and return at least `head_size`. Use the MLA rule (`kv_lora_rank + qk_rope_head_dim`, or `head_dim` when `compress_ratios` is set), then `head_dim` when set and > 0, then `hidden_size_per_head`, then `hidden_size // total_num_attention_heads`, and 0 when there are no heads (model_arch_config_convertor.py:89-116). The attention and KV-cache sizing consumers can then read it instead of recomputing `hidden_size / heads`.
