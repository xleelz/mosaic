## Fix requests (owning area: attention)

1. `selector.get-attn-backend`: derive the kind (`encoder_only` → encoder_only_attention, `encoder_decoder` → cross_attention, MLA ± sliding window, sliding window, full). Look it up in a new `attention-backend-per-kind` config before falling back to `attention-backend` (selector.py:64-102, 180-188).
2. Model `MLAAttention.get_kv_cache_spec` (mla_attention.py:1350): an MLA spec with one latent head and head_size 576, `cache_dtype_str` = the layer's kv_cache_dtype, `kv_quant_mode` from the dtype, and the fp8_ds_mla page of 656 B/token. Route `gpu-model-runner.get-kv-cache-spec` (and worker-runner's `attn-utils.get-kv-cache-spec`, which today assumes full attention) to it for MLA models.
3. Add `flashinfer-mla-sparse-sm90-builder.build`. It calls `state.plan(num_rows, kv_lens)` with only the decode rows when `num_prefills > 0` and the layer's `_use_sparse_mha` is true, and with all rows otherwise. Give `plan` num_rows and kv_lens inputs.
