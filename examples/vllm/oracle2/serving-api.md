## Fix requests (owning area: serving-api)

1. **Inkling parser.** Register `inkling` in `reasoning-parser-manager.get-reasoning-parser` (and the tool parser registry), and add an Inkling parser on the ParserEngine with the CONTENT --TOOL_START--> tool transition: preceding text flushed once to content, header metadata discarded, tool call name/arguments extracted (vllm/parser/inkling.py).
2. **LLM.chat batch of conversations.** Accept `messages` as one conversation or a list of conversations; apply `conversation_to_seq` so each conversation becomes one request and one output (llm.py:617, offline.py:426). Same for `enqueue-chat`.
3. **CohereRenderer.** Model the Cohere renderer selected by the renderer registry, including `_role_to_melody` (case-insensitive; assistant->chatbot, developer->system; unknown roles raise ValueError "Unsupported message role").
4. **Responses input items and partial completion.** Let `ServingResponsesRequest.input` be a string or a list of input/output items; compute `should_continue_final_message` (last item an output message or reasoning item with status in_progress/incomplete) and pass add_generation_prompt / continue_final_message into rendering.
