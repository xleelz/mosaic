## Fix requests

### editor
1. **EOL per resource.** Add a `files-eol` config (`auto` | `\n` | `\r\n`) that can be overridden per resource or folder. Make `model-service.create-model` resolve it as `_getEOL` does (modelService.ts:184-191): a resource-scoped value wins, `auto` means the platform default (LF on Linux and macOS). Store `default_eol` (`LF`/`CRLF`) on the `text-model` entry. Verify with oracle-editor-eol-setting-respected-by-root.
2. **Double-click selection.** Model ViewController.dispatchMouse with mouseDownCount 2 (viewController.ts:259-276): a multicursor modifier → lastCursorWordSelect, inSelectionMode → wordSelectDrag, otherwise (when `editor.doubleClickSelectsBlock` is on) try the bracket content, then the string content, then _wordSelect. Give `cursors-controller` a selection (start/end line and column) so the selected range can be asserted. Verify with oracle-editor-double-click-selects-bracket-content.

### exthost (with files-search-scm for the query schema)
3. **TextSearchManager.** Give `ext-host-search.provide-text-search-results` a behavior that builds the provider's options per folder query, including `encoding = toCanonicalName(fileEncoding)` (textSearchManager.ts:223), instead of a stub. files-search-scm: add a per-folder `file_encoding` to `SearchTextQuery` (ITextQuery.folderQueries[].fileEncoding) and pass it through `search-service.text-search-split-sync-async`. Verify with oracle-files-search-scm-text-search-fixes-encoding.

### files-search-scm
4. **create keeps its contents.** `text-file-service.create` must pass `value` (encoded) as the operation's contents; `working-copy-file-service.create` must forward each file's contents to `file-service.create-file` as `content` (textFileService.ts:253-263, workingCopyFileService.ts:372). Verify with oracle-files-search-scm-create-no-encoding-content-string.

### workbench-contribs
5. **Integrated browser open and new tab.** Model `workbench.action.browser.open` and `workbench.action.browser.newTab` as interfaces and register them in the commands registry. newTab opens a browser editor and always opens the URL picker; open opens it (or reuses a matching view) and opens the URL picker only when no URL was given (browserTabManagementFeatures.ts:341-345, 433-437). Verify with oracle-workbench-contribs-browser-new-tab-url-picker.

### notebook-webview
6. **Kernel source actions.** Model NotebookKernelService.getSourceActions: build the NotebookKernelSource menu actions in the caller's context and cache them per notebook. Clear the cache on onWillRemoveNotebookDocument (notebookKernelServiceImpl.ts:134-140, 312-345), so a reopened notebook re-evaluates preconditions.
7. **Output copy MIME filter.** In `notebook-cell-output-actions.cmd-notebook-celloutput-copy`, pick the output item whose MIME is the picked MIME when that is text-based, otherwise the first TEXT_BASED_MIMETYPES item, and copy nothing when there is none (cellOutputTextHelper.ts:109-119). Verify with oracle-notebook-webview-copy-invalid-mime-nothing.
